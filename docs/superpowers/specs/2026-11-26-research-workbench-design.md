# 統一研究工作台：任意數據比較、樣本外驗證與回測

狀態：具體設計，待使用者確認後進入實作計畫。2026-11-26。

## 目標與驗收方式

使用者從同一畫面選擇 X、Y 數值序列，明確定義比較問題，理解相關係數與其限制，保留研究設定，再把同一份設定交給 invest_backtest 驗證可交易規則。研究結果回答三件事：「觀察到什麼關係」「離開訓練資料後是否仍存在」「依目前資料可否做可信的歷史交易模擬」。不把高相關、顯著性、歷史獲利或既有泛化分數當成因果或未來有效機率。

第一個交付包含完整閉環，而非再加一個數據分頁：數據選擇 → 對齊與轉換 → 比較圖與統計 → 時序保留驗證 → 固定買賣規則 → 實際引擎回測 → 同一研究報告。支援任意已登錄的數值序列，不承諾任何外部網站的任意欄位已自動接入。

## 現況查核與資料結論

目前已驗證官方來源、原始回應雜湊、解析、日期與幣別配對、不可變快照重播，以及部分獨立數值驗算。這不等於所有歷史資料完整或具備歷史發布版本。

- 0050、00981A 現有官方價格仍為未調整價格。完整分割／公司行動與配息覆蓋未認證，因此 ETF 總報酬與依賴它的投資績效保持未知。
- 2026-11-21 取得的官方快照包含 2026-11-02 至 11-20 的 15 個研究日期，不是截至 11-26 的即時資料，也不足以單獨建立長期理論。
- 官方淨值與同日折溢價可以依保存的來源重算；兩條官方含息指數是獨立參考序列，不能替代 ETF 的總報酬。
- 未知原始發布時間的歷史資料標為「取得時版本」。資料取得時間不能回填成歷史已知時間。

本地功能分支原先落後遠端主線。2026-11-26 查核 origin/main `2ee9b613bba3d3149a7feaf7faf2ff1ba87e49e4`：PR #29、#32、#33 已合併。最新版已經有瀏覽器研究工作台、搜尋資料庫、跨檔 CSV 匯入、日／月／季明確日曆、轉換、Pearson／Spearman、散點、滾動與 lag 圖、可用時間界線和來源樣本匯出。這些是此次延伸的基礎，不能當成尚未實作而重做。

core/series_research.py 的 analyze 現在提供全樣本描述、滾動與固定 -6..+6 lag 掃描；尚無凍結研究 Recipe、未揭露 holdout、一般化推論或策略回測介接。其 strict 比較 X 與 Y 的可用時間順序，不等於每個歷史交易決策時點都能取得該版本；新流程必須區分兩者。

較早 core/correlation_engine.py 和 core/panel_correlation_engine.py 已有兩種係數、差分、報酬與列位移。driver_validation_engine.py 已有 ABF 專用區塊重抽樣與訓練區間選 lag 的 walk-forward，需審核後沿用。panel 的 generalization_score 是相關強度乘方向一致性，沒有機率校準，也不是交易回測。

invest_backtest 的 contract_backtest.py 已有確定性訊號與成本處理，但其現有 signal_id、月營收與台股 universe 有特定限制；multi_asset/research.py 提供資產績效及配對相關統計，沒有任意研究假說的交易策略閉環。新增介面與契約，保留這些既有路徑。

## 選定方向與替代方案

採用「延伸已合併的瀏覽器工作台」：維持三個 repo 分工，沿用本機 loopback Python 服務、HTML/JavaScript/Plotly 與既有序列處理，用版本化 JSON 保存與交換研究內容。逐步接入更多數據，以既有 ABF 及瀏覽器測試為保護。

替代方案一是只在桌面分析頁加按鈕，成本較低，但會與已合併的瀏覽器產品分散。替代方案二是另寫獨立研究／回測網站，增加重複數據處理、部署與回歸成本。此次不做這兩種方案。

## 使用者看到的畫面

沿用預設啟動的「金融研究工作台」，在既有資料庫、走勢與相關性介面加入以下流程，保留原 ABF 與跨資產資料查核入口。主要操作用中文，技術路徑放在進階設定。

畫面從上到下：

1. **研究問題**：研究名稱；X 數據搜尋；Y 數據搜尋；日期範圍；「同時變動」或「X 領先 Y」；領先長度與單位；兩邊各自的轉換與單位。選擇器同等對待股價／ETF／FX／營收／宏觀／產業／自訂數據。
2. **計算摘要列**：例如「X 月變動率，對 Y 下一月報酬；按月；共同有效期間；使用取得時版本」。若選原始值、跨幣別、未調整價格或未知發布時間，直接寫明限制。
3. **三個結果區塊**：關係（兩種係數、共同樣本與區間）；穩定性（訓練與保留期間、滾動／分狀態結果）；回測條件（可執行或具體缺口）。沒有單一綠燈替使用者宣稱理論成立。
4. **主要圖表**：轉換後序列／散點圖／滾動相關／領先落後圖可切換；訓練與樣本外期間清楚分色；散點可定位觀測日期，圖表顯示實際資料與缺口。跨單位圖用可辨識座標或明示標準化，不能暗中改單位。
5. **下一步**：「執行比較」「保存研究」「驗證保留期間」「建立回測」。回測區顯示規則、成本、成交時點、策略與買入持有比較、權益／回撤／交易明細。
6. **展開明細**：配對表、排除原因、來源／發布與取得時間、方法假設、所有嘗試、設定及資料雜湊。既有官方原始資料與淨值內容留在這裡或原入口，不再要求使用者逐一翻九個分頁才能完成研究。

狀態文字範例：「尚未計算」「可描述比較；歷史發布時間未知」「保留期間尚未揭露」「已揭露；再次調整需新研究版本」「回測未執行：缺完整調整歷史」。設計圖不填入未計算的相關係數或虛構績效。

## 統一數據登錄與時間處理

新增 Series 定義，引用現有 Asset/Instrument 而非取代它。Series 包含 series_id、名稱、instrument/entity（可空）、指標、單位、頻率、時區、貨幣／FX 報價方向、stock/flow 類型、價格／報酬基礎、可交易性、來源與版本、覆蓋狀態。觀測包含經濟期間、值、published_at、acquired_at、vintage、source hash，時間未知明確為 null。

沿用既有 builtin_catalog 與 CSV 匯入，補上 Series 語意與版本欄位，接入目前 multi-asset 請求／官方快照的所有可供描述研究序列（含 00981A、NAV 與獨立參考指數）；現有 ABF 與季度序列保留。CSV 匯入要求指定日期、值、單位、頻率與時間欄位；沒有發布版本時仍可描述研究，但標記不具歷史 PIT 認證。保留原檔雜湊，不因手動勾選而升格品質。舊 CSV／本機資料庫可繼續載入，缺失的新語意明示為未知，不丟棄既有使用者資料。

描述比較採用選定快照，對齊共同的有效觀測期間。跨頻率必須選擇並顯示聚合方式：存量取期末已知觀測、流量在完整期間加總、報酬完整區間連乘；不預設把每月數據複製成每日獨立樣本，不用插值創造樣本。不支持或語意不明的聚合要求使用者另選頻率，不能默默計算。

正 lag 明確代表 X(t) 對 Y(t+lag)；前瞻目標另存 label_start/end。沿用原值、差分、百分比變動與 YoY，新增正值 log return。日頻顯示目前是日曆日還是已驗證交易日，不能把日曆日 shift 稱為下一交易日。先在完整已宣告日曆上轉換，再剔除缺值，避免跳過缺期卻稱為一期變動。分組研究在 entity 內轉換，不能跨公司拼接。非有限值、常數、重複時間衝突與缺口均有 reason code 與排除筆數。

回測特徵只讀取每次決策以前已知的版本，沿用可用時間 max(published_at, acquired_at) 的保守規則。歷史發布版本缺失時不得回填。正式驗證可以在可用性、調整歷史與交易資料符合條件的歷史或之後持續收集的資料上運作。

## 方法與最佳化：先定義問題，再看結果

- 同時計算 Pearson（線性）與 Spearman（單調排序），標出主要方法及其選擇理由。兩者都不能代表所有非線性依賴，也不能推論因果。
- 顯示樣本期間、共同日期數、不同原始發布事件數、缺失比例與滾動／分 regime 比較。分 regime 使用當時可得標記；缺失不補狀態；稀少子群保留未知。
- 原始趨勢值的係數可供描述，但醒目標示可能的共同趨勢與非定態問題，不自動宣稱有效。ADF／KPSS 等診斷不是資料通過的證明；第一版不以它們自動挑選最漂亮轉換。
- 時間序列不能套用預設 IID p 值。推論模式需明確選擇「近似定態、弱依賴」假設，使用有版本與固定 seed 的 circular block bootstrap：成對區塊重抽樣產生 95% 係數區間；在獨立性虛無假設下分別重抽 X/Y 區塊，產生雙尾近似 p 值。明示該 p 值檢驗獨立性，比單純零線性相關更強。區塊長度／重抽次數隨研究保存；結果標明依賴這些假設，不稱為通用最佳方法。
- 推論的工程下限固定為 50 個有效期間、至少 10 個區塊，且兩邊有變異；這是保守的執行門檻，不是統計正確性保證。不滿足、未知假設、重抽樣退化或未支持的 panel pooling，只顯示描述係數和具體原因，p／CI 保持未知。重抽樣有最大嘗試次數，不能因退化資料無限循環。Panel 的推論要另做群聚方法，第一版不把多家公司當獨立重複樣本。
- 掃描的候選序列、轉換、lag 與參數都先列成候選集合並記錄，不能只保存勝出者。對本次完整且有有效 p 值的假說族顯示 Benjamini–Yekutieli 調整（一般依賴情境）；缺失 p 不補 1，另顯示未檢驗數。調整無法修復無效的單項檢驗，也不能消除使用者未記錄的外部嘗試。
- 理論導向由使用者先寫機制、預期方向、領先／同步／落後與可能失效條件。最佳化只在訓練資料／內層時序折中選擇預先宣告候選與目標（例如方向穩定性或訓練內驗證相關），完整展示落選結果。不得依外層樣本外 r、p 或策略績效選擇參數。

## 時序驗證與研究版本

凍結 ResearchRecipe：序列定義與來源快照 hash、轉換／頻率／日曆／lag／目標區間、方法與假設、候選集合、選擇目標與平手規則、seed、訓練／保留分界、walk-forward 設定、成本假設，以及研究理由。

第一版提供按時間切分的固定保留期間與 expanding walk-forward。每折只用當時訓練資料做轉換參數估計、標準化、區塊長度選擇與候選選擇。任何跨越訓練末端的前瞻 label 都 purge，避免邊界洩漏。重疊目標保留標籤區間並依區塊方法處理，不能假設每列獨立。最終保留期間預設不參與候選掃描；揭露後永遠記錄已揭露，修改設定產生新版本，不能重置為乾淨的未見資料。

報告分開列 full descriptive、train、每折 OOS 與最終 holdout。OOS 支持、方向改變與樣本不足都是正常研究結果；不強迫所有假說通過，也不以任意單一係數門檻標成「理論可行」。

## 研究到回測的契約與實作範圍

chain_survey 擁有 Recipe、Series、既有描述比較與研究工作台；invest_backtest 提供新增推論／時序驗證及假說回測服務；market-temperature-dashboard 維持既有 regime 匯出。沿用 series_research 的明確樣本及轉換設定，新增服務核對來源／樣本／設定 hash；既有全樣本描述不需搬家。三者只交換 JSON，不跨 repo import，不改 ResearchSignalV1 或 ABF 專用 backtest 的語意。新增版本化請求／結果 schema，兩邊保存相同契約與 golden fixtures；CLI 驗證請求、原子寫出結果，輸入或引擎失敗不留下看似完成的舊結果。

回測從已保存 Recipe 建立 StrategyRecipe，另選可交易標的。X/Y 可以是任意數據，但宏觀數據、營收或指數參考本身不是自動可交易工具；未指定可交易標的時只做統計／預測驗證。第一版固定規則是單一股票／ETF 的 long/cash：以當時可用 X 的原值或既定轉換值和固定門檻比較，符合預先選定方向則持有，否則持有現金；提供明確更新頻率與最長訊號有效期。門檻可手動先定，或僅在訓練內候選選擇。未來 Y、OOS 結果不能參與下單。

每次決策於明示的交易日收盤後，最早下一個合格交易日開盤成交，價格及公司行動必須有相容基礎與日曆。第一版只做無槓桿、無放空、全額 long/cash，現金利息假設明示；需要顯示與確認佣金、滑價、交易稅／未知適用性、FX 費用等。價格、分割／配息／幣別、日曆或歷史可用性不足時，列出阻擋原因；現有未調整 ETF 快照不會因新介面而變成可用總報酬回測。

執行引擎以每個決策時點重建可用特徵及交易，保留委託、成交、持倉、現金、費用與權益。分開呈現成本前後績效、最大回撤、波動、Sharpe／Sortino 的風險利率假設、換手與交易數；基準為相同期間、價格與資金成本慣例的買入持有及現金。無交易、未滿可比期間、無風險利率未知等均顯示原因。FX 首版可以作為比較／訊號／換匯曝險數據，不模擬外匯槓桿、隔夜利差或衍生品交易。

結果包含 recipe/strategy/input hash、引擎版本與驗證狀態；主畫面核對一致才展示。一旦資料或設定改變，原結果標記過期，重新執行另留版本。保存的研究可匯出完整 JSON 與中文摘要，沒有引擎時仍能查看來源及上次已驗證報告，但不能偽裝為剛執行的結果。

## 驗證與交付

採用獨立可驗算資料：正負線性、非線性單調、常數、缺期、不等頻率、已知滯後、晚發布／修訂、重疊 label、無交易、費用與 FX，及實際官方快照。合成資料永遠標 TEST ONLY。

必須驗證：係數與受信任實作一致；重抽樣可重現且退化有界；全假說族校正；修改未來資料不影響過去特徵／訓練選擇／成交；下一開盤及費用獨立手算；研究與回測的 hash 不符會被拒絕；來源缺失不升格。UI artifact 涵蓋正常探索、缺資料、保留期間、洩漏阻擋、回測結果與小視窗；每個畫面能看懂「比較什麼、證據如何、下一步是什麼」。

完成 ABF 既有回歸、三 repo 適用測試、契約相容、feature PR 與當前 head CI／UI artifact 檢查。新增回測功能的真實資料限制必須列入交付，不能只用合成曲線當市場有效性證明。

## 後續獨立範圍

多因子／偏相關／HAC 模型、共整合／配對交易、更多非線性依賴、完整 panel 群聚推論、多資產組合最佳化、槓桿 FX／利差與更多商業資料源各有自己的假設與測試，後續另列設計；它們不阻擋第一個任意 X/Y 到單標的回測的完整流程。
